# Picora desktop UI

A compact utility inspired by the operating system's emoji picker. Sticker art is the visual focus. Neutral system light/dark surfaces, system selection color, readable Korean and Latin typography using bundled Noto Sans KR (OFL). The picker has search, collection tabs, a dense square thumbnail grid and a short status/footer. A separate larger library provides source browsing, downloaded packs, groups, accounts and settings with stable left navigation. No decorative hero, generated artwork, or web UI.

Keyboard: search on opening, arrows navigate stickers, Enter chooses, Escape hides. Context menus expose original-file copy and group membership. Errors stay visible with retry actions. Windows remain resizable and grids adapt to width; scroll areas handle long source titles and large libraries.
