# Picora

<!-- impeccable:product-schema 1 -->

## Platform
Cross-platform native desktop: Windows, macOS, Linux X11 and Wayland.

## Users and purpose
People who use DCInside and Arca sticker packs in desktop chat. Open a keyboard picker, find a favorite reaction, and paste it without manually saving and uploading each image.

## Stack
Rust throughout; egui/eframe interface and Wry only for the source website's login.

## Confirmed capabilities
Compact picker and separate library window. Search/browse/import both sources. Favorite packs and ordered custom groups. Offline packs, animated previews, optional original-file paste. Auto-paste with fallback including permission-based Wayland integration. Verify Discord and Telegram compatibility.

## Product principles
Keep chat focus predictable; never send a message. Keep sessions private. Make unavailable integrations and copy failures visible. Preserve Korean source content. Make keyboard and mouse equally useful.
