# Picora approved design

Rust throughout; egui/eframe picker and library windows. Windows, macOS, Linux X11 and Wayland. Configurable Ctrl+Shift+Space shortcut. Selection copies an image, hides the picker and attempts one paste into the previously focused app, never sends Enter. Manual paste fallback. Animated previews and original-file paste action. DCInside and Arca browsing/search/URL import; actual Arca website login in a separate Wry helper. Secure persisted session, memory-only if keyring unavailable. Offline downloaded packs, favorite packs, ordered custom sticker groups, recents, SQLite metadata. Single background instance with tray and CLI activation. Async network and decoding. Discord/Telegram manual compatibility targets. Unsigned artifacts, optional autostart, no cloud service.
