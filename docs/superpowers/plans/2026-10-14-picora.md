> Execute inline using executing-plans; verify with test-driven-development and verification-before-completion.

Goal: Build the approved cross-platform Rust sticker picker.
Architecture: Shared Rust domain/storage/providers/media services, egui UI, per-platform clipboard and shortcut adapters, isolated Wry login helper.
Spec: ../specs/2026-10-14-picora.md

## Constraints and review focus
- Preserve initial uncommitted starter; changes stay on feat/picora in current checkout.
- No password collection, cookie logging, invented provider results, or automatic message sending.
- Check malformed URLs, duplicate imports, expired auth, corrupt assets, focus changes and missing desktop permissions.

## Tasks
- [x] 1. Domain and persistence: src/model.rs, src/store.rs, tests/core.rs. Test URL validation, stable IDs, duplicate import, group ordering and persistence, implement SQLite transactions and settings.
- [x] 2. Providers and media: src/providers/{mod,dcinside,arca}.rs, src/media.rs. Fixture-test catalog/detail parsing and explicit auth/schema failures; implement async requests, bounded downloads, thumbnails, animations and offline paths.
- [x] 3. Platform services: src/platform/{mod,clipboard,shortcut,wayland,instance}.rs, src/auth.rs. Test selection sequencing and IPC; implement clipboard lifetime, native/portal input, login cookie capture, keyring, tray and activation.
- [x] 4. UI: src/app.rs and src/main.rs. Wire services into compact picker plus library; implement groups, account/settings, keyboard navigation, progress/errors. Build and smoke-test UI.
- [x] 5. Distribution and review: CI, packaging, README and compatibility matrix. Run fmt, unit/integration tests, clippy, build and available desktop smoke tests; independent code review; document unverified platform/auth behavior.

## Implementation evidence and rulings
- Domain/storage, provider fixtures, media, cancellation, and headless egui keyboard regression tests pass (16 tests). Live DCInside search/detail/image test also passed separately.
- Linux debug build and Clippy, plus Windows cross-target Clippy pass. A macOS cross-check was attempted but cannot compile the Objective-C helper without an Apple SDK; native macOS CI/runtime remains unverified.
- Xvfb/Openbox smoke: actual catalog/thumbnail rendering, import of pack 41982, persisted 33 stickers after restart, Ctrl+Shift+Space activation, Enter selection into an independent X11 receiver, one Ctrl+V and valid PNG, no Enter sent, clipboard retained while hidden, CLI reactivation.
- Review fixes: cache recovery and serialized disk writes; bounded decoding with permits retained by queued events; cancelled queued paste jobs; focus-change protection; separate picker/library filters; deleted-group filter reset; macOS deprecated activation option removed.
- Regression found by desktop smoke: nested egui context access deadlocked keyboard navigation. Headless UI regression reproduced the 10-second panic before the fix; it passes afterward, as does the fresh desktop smoke.
- Ruling: use X11/XWayland for Linux windows because winit 0.30 Wayland visibility/focus methods are no-ops. Portal shortcuts and keyboard/clipboard remain used on Wayland desktops. Cost: XWayland is a runtime requirement.
- Ruling: keep changes uncommitted on feat/picora so the user's original uncommitted starter remains directly reviewable.
- External validation outstanding: real Arca login/markup/search/downloads, real Wayland portals, macOS/Windows native runtime, Discord/Telegram target-app compatibility. See docs/COMPATIBILITY.md; no claim of verified integration is made for those paths.
